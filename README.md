# AddIT Solutions Website

A complete classic static website for AddIT Solutions, positioned as a coaching and consulting firm for Agile teams, PMOs, delivery leaders, and project execution improvement.

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
- Static assets only

## Files

- `index.html` - home page
- `services.html` - detailed services page
- `approach.html` - consulting approach and engagement model
- `about.html` - company positioning page
- `contact.html` - contact and consultation page
- `styles.css` - responsive classic business styling
- `script.js` - mobile navigation, sticky header, and mailto form behavior
- `assets/consulting-workshop.png` - generated hero image

## Run Locally

Open `index.html` directly in a browser, or run:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000/`.

## Deployment

This can be hosted on any static hosting platform, including Netlify, Vercel, Hostinger, cPanel, GitHub Pages, or any standard web server.
